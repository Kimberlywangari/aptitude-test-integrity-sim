# Aptitude test integrity: cheat-flagging preparation project

A small preparation project that practises building an integrity / anti-cheating
layer for an online multiple-choice aptitude test.

**Everything here uses simulated data.** The sittings, the "honest" timing and the
cheating behaviours are all generated by code in this repo. Results describe how the
detectors behave on that simulated data only. They say nothing about real candidates
and this project is not the capstone itself.

Flags are meant for human review. Nothing is auto-rejected.
